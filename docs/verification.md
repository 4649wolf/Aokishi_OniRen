# 検証記録

検証日：2026-10-27（JST）

## 自動テスト

Node標準testで11項目を実施し、11/11成功。

- 提供MIDIの40音、tempo、先頭音、末尾音、全体長。
- YIN：110〜880Hzの基本音と倍音を含む信号、無音、不規則ノイズ。
- MIDIどおりの全曲でクリア、オクターブ違いで失敗。
- 無音、短音が連続する箇所の外れ、赤い区間記録。
- ±100centの境界、一時的な外れからの復帰、休符、再挑戦初期化。
- 時刻飛び、未判定音による誤クリア防止。
- 過去の再生Promiseの拒否が新しい試行を止めない。
- 音声処理resume待ち中の連打で二重開始しない。
- rAFが動き続けても動画時刻が2秒間進まなければ中断。

不具合3ケースは修正前の失敗、修正後の成功を確認。

## Chrome実ブラウザー

- 動画の緑が透過し、背景が見えることを画面で確認。
- 試聴WAVの再生と経過時刻の進行。
- マイク権限拒否の案内と開始ボタン無効化。
- 幅390pxで横スクロールなし。
- Web AudioのMediaStreamへMIDI40音を合成して入力し、実アプリのYIN→Judge→クリアを確認。
- 合成映像のMediaStreamをカメラ層に接続し、動画の下に表示されることを確認。
- 音程外れで動画5.355秒に失敗、動画は停止、音程Canvasに赤い画素1652点を検出。
- 無音で動画5.467秒に失敗、中断ボタンで中断、再挑戦、カメラ・マイク解除と開始ボタン無効化を確認。
- 合成音声の遅延補正は50ms。実機用初期値120msの妥当性を証明する検証ではない。

## 受入が残る範囲

- 実際の歌声、実マイク・実カメラ、端末ごとの入力遅延。
- Android/iPhone実機、Safari/Firefox、低性能端末での処理速度。
- 人が聴いて判断する動画・MIDI・歌声の最終的なタイミング一致。
- 音程推定は75〜1200Hzの単音を対象とし、多声音・スピーカー回り込みは正しく判定できない場合がある。
