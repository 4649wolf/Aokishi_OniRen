# 青騎士さん専用鬼レンチャン

- 目的：提供された1曲の指定区間を歌い、MIDIとの音程差で即失敗／最後まで成功ならクリア。
- 拡張、選曲、ログイン、サーバー保存は作らない。
- 採用判断：ビルド・外部ライブラリ不要の静的HTML/CSS/JavaScript。GitHub Pagesのリポジトリ配下で動く相対URLのみ。
- 代案：React等は単曲に対して依存とビルド負荷が増える。サーバー判定はPages単独で完結しない。
- 素材：本番.mp4を変更せず同梱し、WebGLで緑を透過。背景→任意のカメラ→動画→MIDIバー。
- 同期：動画5.000秒をMIDI0秒に対応。176 BPM、40音、10.397725秒。入力遅延補正120ms固定。
- 判定v1.2：±200cent、有声の音程外れ1秒／無音1.5秒で失敗。音の立ち上がり60ms・終端25msを猶予。正解で外れをリセット、0.25秒以上の無音でも外れ累積をリセットする。無音を有声の外れ累積に加算しない。
- 全音に判定サンプルを要求し、タブ非表示、デバイス切断、処理の大きな途切れは中断扱い。
- UI：暗い背景、青い主操作、18pxの白い目標バー、正解の通過部分は黄色。赤は実際に歌った音高へ別のバーとして描く。無音は赤い音高を作らない。失敗／クリアはステージを覆う大文字。
- カメラ：機器／仮想カメラ選択、一覧更新、クロマキーなし／緑／青、強さ調整。背景→処理済みカメラCanvas→本番動画Canvas→音程バー。WebGLとCPU代替で同じ閾値を使う。
- v1.1追加指定：ヘッダーはタイトルだけ。パネル副題・注意書き・凡例・音ズレ調整と遊び方・目標/あなた/cent表示を削除。02見出しは「曲に挑戦する」。faviconは維持。
- 参考aaaa.mp4は視覚参照のみ。本番素材を差し替えず、太鼓の上に紫地・白枠の「歌い出しまで」吹き出しを動画5秒未満に描画する。
- 試聴は本番.wavを何度でも再生、任意のリピート。挑戦開始時は試聴停止。
- カメラ／マイクはクリック後に許可要求。外部送信・録音保存なし。
- 公開先：ユーザー指定 https://github.com/4649wolf/Aokishi_OniRen.git 。既存データがないことを確認済み。
- 実生歌、マイク遅延、カメラ実機、モバイル実機は別途受入が必要。
