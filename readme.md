# 青騎士さん専用鬼レンチャン

提供された **All Teen Bean** の指定区間だけに対応した、1曲専用カラオケアプリです。

- 公開先：<https://4649wolf.github.io/Aokishi_OniRen/>
- リポジトリ：<https://github.com/4649wolf/Aokishi_OniRen>

## 遊び方

1. ヘッドホンまたはイヤホンを接続します。
2. 「課題曲を聴く」でお手本を聴きます。何度でも再生でき、繰り返しも可能です。
3. 「マイクを接続」を押し、ブラウザーの許可を出します。
4. 必要なら「カメラを接続」を押します。カメラなしでも遊べます。
5. 「挑戦をはじめる」を押し、「歌い出しまで」の吹き出しと太鼓のカウントを見て、「1」が消えたら歌います。
6. 白い太めの音程バーに合わせて歌ってください。合っている通過部分は黄色に変わります。青い現在地バーが左から右に進み、数秒ごとに次の区間へ切り替わります。

音程が外れると、実際に歌った高さに赤いバーが出ると同時に失敗します。白い目標バーはそのまま残るため、高すぎたか低すぎたかが分かります。無音では赤い音高を作りません。歌声の音程を検出できない状態が0.25秒続いても失敗します。40音を最後まで通過すると「クリア」を表示します。「もう一度挑戦」で最初からやり直せます。

## ノートの高さ・音程テスト

- 「ノートの高さ」の初期値は-12です。−／＋で半音ずつ-24〜+12へ動かせます。「原曲」で0に戻ります。挑戦中は変更できません。
- 変更するのは目標ノートと基準音です。試聴WAVと本番動画の音源・再生速度は原曲のままです。
- 「音程テスト」を押すとマイクを使い、歌った音名・周波数・入力レベルを確認できます。小さい声で検出されない場合は「入力感度」を上げます（1〜4倍、挑戦でも同じ感度を使用）。
- 「基準音」は、現在のノート設定に対応した先頭の音を鳴らします。例えば0はC4、-12はC3です。
- テストを終了してもマイク接続は維持します。挑戦開始時は音程テストと基準音を止めます。「接続を解除」でマイクも停止できます。

## カメラ・VTuberのクロマキー

1. 人物用のカメラ、またはVTuber映像を出力する仮想カメラを準備します。OBSを使う場合はOBS側の仮想カメラを開始します。
2. アプリの「カメラを接続」で許可を出し、「カメラ・クロマキー」を開きます。
3. 「カメラ」から使用する機器／仮想カメラを選びます。一覧に出ない場合は「更新」を押します。
4. 緑／青の単色背景を用意し、「クロマキー」を背景と同じ色に設定します。「透過の強さ」で抜け方を調整できます。「なし」に戻すと元の映像を表示します。

人物やキャラを残し、透過した部分から提供された背景画像が見える順番です。背景色と衣装の色が重なる場合は、もう一方の背景色を使ってください。接続する機器はブラウザーにカメラとして認識される必要があります。

## 判定・同期

- 正解範囲：MIDIの目標から±200cent（±2半音）。オクターブ違いも外れです。
- 失敗：確認された音程外れを赤く描く、その更新で失敗。瞬間的な推定ノイズは約30ms確認し、その確認待ち中は赤く描きません。
- 無音・音程未検出は0.25秒。ノートごとの立ち上がり猶予にも未検出時間を数えるため、短い音が続いても判定が抜けません。休符・カウント中は除外します。
- 各ノートには正しく歌った判定が必要です。未判定のまま音が終わっても失敗となり、飛ばしてクリアにはできません。
- 音の立ち上がり60ms、終わり25msは音程比較の猶予です。無音の検出はこの区間も含みます。
- MIDIは40音、176 BPM、約10.397725秒。動画5.000秒をMIDI0秒に対応させています。
- 入力遅延補正：120ms固定。ユーザー指定により画面の調整・遊び方・音程数値表示は削除しています。
- 遅延はマイク・音声機器・ブラウザーごとに異なります。Bluetooth機器は特にずれる場合があります。
- タブを隠す、動画が止まる、音声処理が停止する、マイクが切れる、判定が大きく途切れる場合は「中断」です。未判定の音を飛ばしてクリアにはしません。

## 映像・プライバシー

最下層が背景画像、次が左右反転したクロマキー対応カメラ、最上層が本番動画と音程バーです。本番動画の緑色と、カメラで選択した緑／青を別々に透過します。WebGLが使えない環境はCanvas 2Dに切り替えます。背景・カメラ・動画を暗めにし、バーは原寸18pxの太さで描画します。白が目標、黄色が正解部分、赤が実際に外れた音高です。

カメラ・マイクは端末内で処理します。録音・録画・外部送信・アカウント登録・サーバー保存はありません。デバイスの許可は接続ボタンを押した後に要求します。「接続を解除」で停止できます。

## GitHub Pagesで公開する

ビルドやnpmパッケージのインストールは不要です。

1. このフォルダーの内容を `4649wolf/Aokishi_OniRen` の `main` ブランチ直下へ配置します。`assets` と `src` の階層を保ってください。
2. GitHubの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選びます。
3. **main / (root)** を選んで保存します。
4. 公開が完了したら上記URLで開きます。カメラとマイクにはHTTPSが必要です。

公開方式は[GitHub公式手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)に沿っています。提供素材はそのまま同梱しています。公開時の素材の取り扱いはリポジトリ所有者の管理下です。

## ローカルで確認する

Pythonがある場合は、このフォルダーで次を実行して `http://127.0.0.1:4173` を開きます。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

`index.html` をファイルとして直接開く方法では、MIDIの読み込みとマイク権限が正常に動かないことがあります。localhostまたはHTTPSで利用してください。

Node.js 20以降がある場合、判定などの自動テストは `npm test` で実行できます。アプリの実行自体にはNode.jsも不要です。
