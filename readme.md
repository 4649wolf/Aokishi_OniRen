# 青騎士さん専用鬼レンチャン

提供された **All Teen Bean** の指定区間だけに対応した、1曲専用カラオケアプリです。

- 公開先：<https://4649wolf.github.io/Aokishi_OniRen/>
- リポジトリ：<https://github.com/4649wolf/Aokishi_OniRen>

## 遊び方

1. ヘッドホンまたはイヤホンを接続します。
2. 「課題曲を聴く」でお手本を聴きます。何度でも再生でき、繰り返しも可能です。
3. 「マイクを接続」を押し、ブラウザーの許可を出します。声を出すと「あなた」に検出した音程が表示されます。
4. 必要なら「カメラを接続」を押します。カメラなしでも遊べます。
5. 「挑戦をはじめる」を押し、動画の太鼓の「1」が消えたら歌います。
6. 白い音程バーに合わせて歌ってください。青い現在地バーが左から右に進み、数秒ごとに次の区間へ切り替わります。

音程が外れた箇所は赤くなります。外れまたは無音が続くと動画が停止して大きく「失敗」、40音を最後まで通過すると「クリア」を表示します。「もう一度挑戦」で最初からやり直せます。

## 判定・同期

- 正解範囲：MIDIの目標から±100cent（±半音）。オクターブ違いも外れです。
- 失敗：判定対象時間内の外れ・無音が250ms継続。
- 音の立ち上がり60ms、終わり25msは猶予。短い音の境界で連続する外れをリセットしません。休符は判定しません。
- MIDIは40音、176 BPM、約10.397725秒。動画5.000秒をMIDI0秒に対応させています。
- 初期入力遅延補正：120ms。「音ズレの調整・遊び方」で変更できます。
- 遅延はマイク・音声機器・ブラウザーごとに異なります。判定が歌声より先行する場合は遅延補正を増やします。Bluetooth機器は特にずれる場合があります。
- タブを隠す、動画が止まる、音声処理が停止する、マイクが切れる、判定が大きく途切れる場合は「中断」です。未判定の音を飛ばしてクリアにはしません。

## 映像・プライバシー

最下層が背景画像、次が左右反転したカメラ、最上層が本番動画と音程バーです。本番動画の緑色をWebGLで透過し、WebGLが使えない環境はCanvas 2Dに切り替えます。背景・カメラ・動画を暗めにし、目標バーは白く太くしています。

カメラ・マイクは端末内で処理します。録音・録画・外部送信・アカウント登録・サーバー保存はありません。デバイスの許可は接続ボタンを押した後に要求します。「接続を解除」で停止できます。

## GitHub Pagesで公開する

ビルドやnpmパッケージのインストールは不要です。

1. このフォルダーの内容を `4649wolf/Aokishi_OniRen` の `main` ブランチ直下へ配置します。`assets` と `src` の階層を保ってください。
2. GitHubの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選びます。
3. **main / (root)** を選んで保存します。
4. 公開が完了したら上記URLで開きます。カメラとマイクにはHTTPSが必要です。

公開方式は[GitHub公式手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)に沿っています。提供素材はそのまま同梱しています。公開時の素材の取り扱いはリポジトリ所有者の管理下です。

## ローカルで確認する

Pythonがある場合は、このフォルダーで次を実行して `http://127.0.0.1:4173` を開きます。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

`index.html` をファイルとして直接開く方法では、MIDIの読み込みとマイク権限が正常に動かないことがあります。localhostまたはHTTPSで利用してください。

Node.js 20以降がある場合、判定などの自動テストは `npm test` で実行できます。アプリの実行自体にはNode.jsも不要です。
